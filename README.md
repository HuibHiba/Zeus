# Zeus online

Tactisch voetbalspel: spelers vrij neerzetten, tactieken bepalen en zien waarom ze werken. Ontwerp en planning staan in de Obsidian-vault; deze repo bevat alleen code.

Status: fase 1a, taken 1–13 afgerond. Spelers bewegen naar tactiekposities, twee spelfases volgen het balbezit en de bal heeft eigen natuurkunde. Passen, waarneming en beslissingen volgen vanaf taak 14. Zie `CLAUDE.md` voor de afspraken en `docs/hervatten.md` om verder te werken.
