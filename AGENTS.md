# Instructies voor Codex in deze repo (Zeus online)

Lees eerst `CLAUDE.md`, `docs/hervatten.md` en, als je door het nachtsysteem wordt gestart, `nacht/REGELS.md`.
Werkverdeling: Codex bouwt in `sim/` en `godot/`; Claude doet data, kalibratie, scripts en documentatie. Je mag nooit
`git add -A`, `git stash`, `git reset` of `git checkout` gebruiken: een andere sessie werkt tegelijk in `scripts/`.
Documentatie en commitberichten zijn Nederlands, code en identifiers Engels, zoals in de bestaande bestanden.
