Gaffer's Notebook - data sources besides Wyscout (see WYSCOuT_NOTICE.txt)
=======================================================================

No raw data from these sources is included in the game. Only averages and
percentiles computed by the game developers were used, mainly for default tactic
positions and line heights per phase. These modifications and the simulation's
behaviour are not endorsed by the dataset authors, the DFL, Sportec Solutions
or SkillCorner. No claim of realistic prediction is made.


1. DFL / Sportec Solutions integrated dataset
---------------------------------------------
Bassek et al., "An integrated dataset of spatiotemporal and event data in elite
soccer", Scientific Data (2025). Dataset: figshare record 28196177
https://api.figshare.com/v2/articles/28196177
Measured: 7 Bundesliga matches 2022/23 (25 Hz positions and events): player and ball
speeds, shot speed, line heights. Changes were made by the game developers.
License: Creative Commons Attribution 4.0 International (CC BY 4.0), according to
the Scientific Data / figshare metadata (checked 2026-10-13).
https://creativecommons.org/licenses/by/4.0/
Not yet confirmed: the licence text for use in a released product, and the
DOI of the article and dataset (not recorded in the project; the figshare record
number above is).


2. SkillCorner Open Data
------------------------
https://github.com/SkillCorner/opendata - credit: SkillCorner
Measured: 20 A-League 2024/25 matches: running speeds, accelerations, pass speed,
line heights and phase templates.
